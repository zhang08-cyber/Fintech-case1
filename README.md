## 一、项目简介

本项目使用 Python 获取 **贵州茅台（600519）** 2023 年全年日K线行情数据，
完成数据清洗、技术指标计算与可视化，并导出标准化数据集。

核心目标：
- 掌握金融数据的获取方式（akshare 接口）
- 掌握 pandas 数据清洗与指标计算
- 掌握 matplotlib 数据可视化
- 完成一个可复用的量化分析基础模块
